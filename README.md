# Heisenberg Climb

**BCS & BB: The Climb** — 融合《风骚律师》(Better Call Saul) 与《绝命毒师》(Breaking Bad) 世界观的爬塔 Roguelike 卡牌构筑游戏。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。手机可访问同一局域网 IP。

## 操作

- **点击手牌**：选中 / 取消选中
- **点击敌人**：对选中卡牌指定目标并打出
- **End Turn**：结束回合
- 主菜单可选 Walter / Saul / Jesse / Mike 进入测试战斗

## 技术栈

- 原生 HTML5 + CSS3 + JavaScript (ES6+)
- Canvas 2D（主画面）+ DOM（UI / 文字 MUD）
- Vite 开发与打包
- localStorage 存档
